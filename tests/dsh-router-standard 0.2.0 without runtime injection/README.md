# 网页版中国象棋

一个纯 HTML / CSS / JavaScript 实现的网页中国象棋小游戏，支持：

- **玩家 vs AI**：玩家可执红先手或执黑后手，点击走子，AI 自动应招。
- **AI vs AI**：两方 AI 自动对弈，可暂停/继续。
- 三种难度：简单、普通、困难（AI 搜索深度 1/2/3 层）。
- 完整中国象棋规则：
  - 车、马、炮、兵（卒）、象（相）、士（仕）、帅（将）走法
  - 蹩马腿、塞象眼、炮架
  - 九宫、过河兵、将帅不可照面
  - 将军、将死、困毙、三次重复局面判和
- 悔棋（玩家 vs AI）、翻转棋盘、走子高亮、对局记录。

## 运行方式

无需安装依赖，直接双击打开 `index.html`，或用任意静态服务器：

```bash
# 例如 Python
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 文件结构

```
.
├── index.html          # 页面结构
├── css/
│   └── style.css       # 棋盘、棋子样式（程序生成的木质纹理）
└── js/
    ├── xiangqi.js      # 棋盘、规则、走法生成、将军判定
    ├── ai.js           # Minimax + Alpha-Beta 剪枝 AI
    └── main.js         # 界面渲染、玩家交互、AI vs AI 调度
```

## 说明

- 棋盘线条、木质纹理均为 CSS/SVG 程序生成，不需要联网加载任何外部素材。
- 坐标采用 `(行,列)`：红方在下方，黑方在上方。
- AI 评估包含子力价值与棋子位置价值表；相同评分下会引入少量随机性，使棋风不单调。
