# 中国象棋 · 网页版 (Xiangqi Web)

一个零依赖、纯前端的中国象棋游戏：**玩家 vs AI** 与 **AI vs AI** 双模式。
棋盘采用真实木纹素材（联网加载，离线自动降级为程序化纹理），全部音效由 Web Audio 合成，无需任何外部资源文件即可运行。

---

## ✨ 功能

- **两种模式**：玩家 vs AI（可选执红/执黑）、AI vs AI（观战模式，可调速度）
- **四档 AI 难度**：简单 / 中等 / 困难 / 大师（搜索深度、时限、随机性不同）
- **完整规则**：九宫、士象、蹩马腿、塞象眼、炮架、飞将（面将）、过河兵横向、将死/困毙判负、循环局面判和、自然限着（60 回合）判和
- **中文记谱**：炮二平五、兵三进一、傌二进三 等标准记法，实时棋谱列表
- **交互反馈**：选子高亮、合法落点圆点/吃子红圈、上一步高亮、将军脉冲警示、走子动画、吃子面板
- **后悔与认输**：悔棋、认输、重新开始、暂停/继续（AI vs AI）
- **音效开关**：落子/吃子/将军/胜负提示音

## 🚀 运行

### 方式一：直接双击
双击 `index.html` 即可在浏览器打开（`file://` 兼容，无模块依赖）。

### 方式二：本地服务器（推荐，可加载在线木纹素材）
```bash
# 任选其一
python -m http.server 8765
# 或
node serve.js
```
然后访问 <http://localhost:8765>。

素材说明：棋盘木纹通过 `loremflickr.com`（Flickr 图片，CORS 开放）联网获取；
无网络时自动绘制内置程序化木纹，视觉依旧完整。

## ⌨️ 操作

- 点击己方棋子选中 → 点击高亮落点走子；点击其他位置取消选择
- 按钮：`↩ 悔棋` `🏳 认输` `❚❚ 暂停/▶ 继续` `↻ 重新开始` `☰ 菜单` `🔊 声音开关`

### 演示/自动开局（URL 参数）
```
?mode=aiai&diffR=hard&diffB=medium&speed=800      # AI vs AI 直接开打
?mode=pvp&player=b&diff=hard                       # 玩家执黑、AI 执红
?mode=pvp&player=r&diff=hard&sel=6,6&to=6,5        # 玩家执红并自动走 兵三进一
```

## 🧠 AI 实现

- **极小极大 + Alpha-Beta 剪枝**，**迭代加深** + 时限控制（主线程同步搜索，深度自适应）
- **着法排序**：先吃子（MVV-LVA）+ 历史启发，显著提升剪枝效率
- **评估函数**：子力价值 + 位置价值表（马象炮车各有专属表）+ 过河兵奖励

| 难度 | 最大深度 | 时限 | 随机性 | 典型耗时（首步） |
| --- | --- | --- | --- | --- |
| 简单 | 1 | 350ms | 65% | <20ms |
| 中等 | 2 | 900ms | 30% | ~40ms |
| 困难 | 3 | 2000ms | 12% | ~150ms |
| 大师 | 5 | 3800ms | 5% | 1.5~4s |

## 🗂 文件结构

```
xiangqi/
├── index.html          入口页面
├── style.css           界面样式（深色木纹主题，移动端自适应）
├── serve.js            极简静态服务器（验证/本地用）
├── js/
│   ├── rules.js        规则引擎：走法、将军、合法着法、中文记谱（浏览器+Node 通用）
│   ├── ai.js           AI 引擎：αβ 搜索、迭代加深、评估
│   ├── texture.js      联网素材加载（在线木纹 + 离线降级）
│   ├── renderer.js     Canvas 渲染：棋盘/棋子/高亮/动画
│   ├── sound.js        Web Audio 合成音效
│   ├── game.js         对局控制器：回合调度、悔棋、判和等
│   └── main.js         界面接线、菜单、事件、URL 参数
├── test-rules.js       规则引擎单元测试（node test-rules.js）
├── test-ai.js          AI 引擎测试：一步杀/不送子/自对弈/性能
└── verify.js           端到端验证：CDP 驱动 Edge headless，真实点击、截图
```

## ✅ 测试与验证

```bash
node test-rules.js   # 规则：首步 44 种着法、马腿象眼、炮架、番将、绝杀、记谱
node test-ai.js      # AI：一步杀、不吃亏、自对弈无崩溃、耗时达标
node verify.js       # 端到端：headless Edge 真实鼠标点击走子、AI 应着、悔棋/认输/重开/执黑先手、file:// 直开
```

`verify.js` 需要本机安装 Edge（Windows 默认路径已适配），自动起本地服务并在 5 个场景断言后产出 `shot-*.png` 截图。
